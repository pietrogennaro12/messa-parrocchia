# Messa Parrocchia

Programma che prepara la presentazione PowerPoint della Messa: legge letture e preghiere dal sito della CEI,
inserisce i canti da un PDF della parrocchia e salva un file `.pptx` pronto da proiettare.

- **Installazione e uso**: vedi [LEGGIMI.md](LEGGIMI.md) (Mac e Windows).
- **Novità di ogni versione**: vedi [CHANGELOG.md](CHANGELOG.md).
- **Scaricare**: sezione *Releases* di questa pagina.

Il PDF dei canti e le impostazioni personali non fanno parte di questo repository (vedi `.gitignore`).
